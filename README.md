# DAYFRAME 0.2 — 인수인계 개선판

Flutter 개인 플래너 소스입니다. APK나 실기기 검증 완료본은 아닙니다.
원본 인수인계의 소스를 이 저장소에 반영했습니다.

## 실행

Flutter stable(Dart 3.9 이상), Android SDK/JDK 17 및 Android 실기기를 준비하세요.
이 폴더에서 실행합니다. `flutter create .`로 직접 덮어쓰지 마세요.

```sh
flutter pub get
flutter analyze
flutter test
flutter devices
flutter run
```

Windows에서는 `./setup_windows.ps1`도 사용할 수 있습니다. Android 플랫폼 파일과 네이티브 연동이 이미 포함되어 있어 Python 준비 명령은 필요하지 않습니다.
플랫폼을 새로 준비해야 할 때에만 Python 3으로 `python tools/prepare_android.py`를 실행하세요. 이 스크립트는 임시 프로젝트에서 기본 플랫폼을 생성한 뒤 네이티브 코드를 적용합니다.
앱의 lib/test/pubspec 파일은 덮어쓰지 않습니다. 생성 후 같은 명령을 다시 실행할 수 있습니다.
기본 applicationId는 `com.example.dayframe`입니다. 기존 설치 앱과 다르면 별도 앱으로 설치되므로,
기존 데이터가 자동 공유되지 않습니다. 기존 앱의 applicationId와 일치시키려면 패키지 설정과 Kotlin 경로도 함께 조정해야 합니다.

## 개선 내용

- 일정·메모·체크리스트·목표 편집기의 컨트롤러를 다이얼로그 수명에 맞춰 해제합니다.
  날짜/시간 선택 후 이미 닫힌 화면에 setState하지 않도록 확인합니다.
  제보된 오류 로그가 없어 동일 원인으로 확정하지는 않았습니다.
- 새 체크리스트의 기본 완료 목록을 수정 가능한 목록으로 만들어 첫 완료 체크 오류를 수정했습니다.
- 잠금 요약 프리뷰의 큰 시계를 제거하고 일정 2개, 체크리스트 3개, 목표 2개, 메모 1개로 줄였습니다.
  작은 화면이나 큰 글자에서는 스크롤할 수 있습니다. 빠른 완료 체크와 상세 편집은 오늘/성경 화면에서 합니다.
- 성경을 실제 장별 절 수를 사용하는 31,102절 단위로 전환했습니다. 책/장/절 이동, 여러 절 완료,
  날짜별 누적 기록, 미완료 위치 이동, 절 메모를 지원합니다. 본문은 포함하지 않습니다.
  절 구분 기준과 출처는 [VERSE_DATA_SOURCE.md](VERSE_DATA_SOURCE.md)를 확인하세요.
- 저장 키 `dayframe_data_v1`은 유지하고 내부 schemaVersion을 2로 올립니다.
  기존 장 완료는 그 장의 모든 절에 원래 날짜를 적용하고, 기존 장 메모는 별도 필드로 보존해 해당 장에서 보여 줍니다.
  기존 커서는 해당 장의 첫 절로 이동합니다. 처음 이전하기 전 원본 JSON을
  `dayframe_data_v1_pre_verse_backup`에 남깁니다. v0.2 저장 이후 구버전 앱으로 돌아가 쓰는 것은 지원하지 않습니다.
- 개인정보 숨김은 신규 사용자에게 기본 활성화됩니다. 기존 명시적 설정은 유지합니다.
  일정·체크리스트·목표·메모 제목과 내용 모두 프리뷰/네이티브 요약에서 가립니다.

## 실제 Android 잠금 요약 (실험 기능)

1. 앱 설정에서 **잠금 요약 사용**을 직접 활성화합니다.
2. **네이티브 요약 열기**로 Android 화면을 확인합니다.
3. 휴대폰 빠른 설정 패널의 편집에서 **DAYFRAME** 타일을 추가합니다.
4. 폰을 잠근 뒤 패널에서 타일을 눌러 표시 여부를 확인합니다.

이 기능은 Flutter 프리뷰와 별개의 Kotlin Activity입니다. `setShowWhenLocked`로 잠금 위 표시를 요청하고,
명시적인 타일 탭으로 시작합니다. 화면 켜짐 감지, 자동 실행, 보안 잠금 해제, 풀스크린 알림 권한을 사용하지 않습니다.
Android 16 및 One UI에서 잠금 중 빠른 설정 접근/Activity 실행을 제한하면 잠금 해제가 필요하거나 실행이 제한될 수 있습니다.
삼성 기기 동작은 아직 검증되지 않았습니다. 일반 앱 코드로 매번 자동 표시를 보장하지 않습니다.

네이티브 화면은 저장된 요약을 읽는 읽기 전용 화면입니다. 체크/편집은 잠금을 해제하고 앱에서 진행하세요.
요약은 앱 시작·복귀·데이터 변경 시 갱신되며 백그라운드에서 매일 자동 갱신되지 않습니다.
다른 날짜의 캐시는 보여 주지 않고 앱에서 갱신하도록 안내합니다. 기기 날짜·시간대 변경은 앱 복귀 시 반영됩니다.
비활성화하면 네이티브 캐시를 비웁니다. 개인정보 표시를 허용하면 요약 내용이 Android 내부 앱 저장소에
평문으로 캐시됩니다. 민감한 기록에는 숨김 설정을 유지하세요. 앱 저장 자체는 암호화·백업 기능을 제공하지 않습니다.
