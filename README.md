# DAYFRAME

성경 읽기, 캘린더·메모, 체크리스트, 장기 플랜을 함께 보는 Android 잠금화면 플래너.

- 성경 읽기·권/장별 진행도·읽음/메모/북마크 돌아보기. 지난 구절을 열어도 읽던 위치는 유지한다.
- 날짜를 한 번 누르면 선택, 다시 누르면 일정 등록. 메모 영역에서 등록·수정·삭제.
- 설정의 **화면 순서**에서 영역을 드래그해 재배치. 캘린더·메모는 함께 이동하고, 넘치는 항목은 좌우 페이지로 넘긴다. 닫기는 하단 고정.
- 월간 달력 아래 메모가 들어가지 못할 때만 주간으로 축소한다. 체크리스트·장기 플랜이 넘치는 경우에는 월간을 유지한다.
- 설정에서 내용 숨김, 다크 모드, 표시 항목과 잠금화면 작성 권한 변경.
- 잠금화면 캡처 허용. 잠금 해제 뒤 도착한 자동 실행 요청은 표시하지 않는다.

```sh
flutter pub get
flutter run
```

**설정 → 성경 읽기·기록**에서 개역개정 본문, 진행도와 지난 기록을 확인한다. 본문은 앱에 포함되어 오프라인으로 읽을 수 있다. 원본의 수정·검증 내역은 [BIBLE_DATA.md](BIBLE_DATA.md)에 있다.

잠금화면은 **설정 → 표시 권한 허용 → 잠금화면 사용**에서 켠다. 재부팅 후에는 다시 켜야 하며, 자동 실행은 기기 설정에 따라 제한될 수 있다.
기록은 기기에 저장되며 앱을 삭제하면 함께 지워진다.
