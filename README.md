# DAYFRAME

하루의 말씀, 캘린더·메모, 체크리스트, 장기 플랜을 담는 Android 잠금화면 플래너.

- 말씀을 읽으면 그 자리에서 오늘 읽기가 완료된다. 화면을 다시 열거나 자정이 지나면 다음 읽을 구절로 이동한다. 화살표·스와이프로 더 읽을 수 있고 본문은 접을 수 있다.
- 설정의 **말씀과 기록**에서 연속 읽기·진행도, 날짜별 읽은 구절, 메모와 북마크를 돌아본다. 개역개정 본문은 오프라인으로 제공한다.
- 날짜를 한 번 누르면 선택, 다시 누르면 일정 등록. 메모 영역에서 등록·수정·삭제.
- 설정에서 영역 순서, 다크 모드, 내용 숨김과 잠금화면 작성 권한을 바꾼다. 캘린더·메모는 함께 이동하며 메모가 잘릴 때만 주간으로 줄어든다.

```sh
flutter pub get
flutter run
```

잠금화면은 **설정 → 표시 권한 허용 → 잠금화면 사용**에서 켠다. 자동 표시는 기기 설정에 따라 제한될 수 있으며 재부팅 뒤에는 다시 켜야 한다.
기록은 기기에 저장되며 앱을 삭제하면 함께 지워진다.

코드: `lib/core/bible/`(본문·위치·읽기), `lib/screens/`(화면), `lib/widgets/`(공통 UI).
