# DAYFRAME

성경 읽기, 캘린더·메모, 체크리스트, 장기 플랜을 함께 보는 Android 잠금화면 플래너.

- 성경 절 이동, 읽음 표시와 메모. 본문은 아직 포함하지 않는다.
- 날짜를 한 번 누르면 선택, 다시 누르면 일정 등록. 메모 영역에서 등록·수정·삭제.
- 캘린더·메모는 함께 배치하고, 넘치는 영역은 좌우 페이지로 이동. 닫기는 하단 고정.
- 설정에서 내용 숨김, 다크 모드, 표시 항목과 잠금화면 작성 권한 변경.
- 잠금화면 캡처 허용. 잠금 해제 뒤 도착한 자동 실행 요청은 표시하지 않는다.

```sh
flutter pub get
flutter run
```

잠금화면은 **설정 → 표시 권한 허용 → 잠금화면 사용**에서 켠다. 재부팅 후에는 다시 켜야 하며, 자동 실행은 기기 설정에 따라 제한될 수 있다.
기록은 기기에 저장되며 앱을 삭제하면 함께 지워진다.
